# Tank Landing

Вёрстка лендинга автодилера по макету из Figma. Учебный проект для портфолио — **в работе**.

> Макет взят из открытого источника для практики. Проект не связан с компанией «Авторусь» и брендом Tank.

## Стек

- Vite
- JavaScript (без фреймворков)
- SCSS, методология БЭМ
- Адаптив: десктоп 1920 → мобильная 375

## Что сделано

- [x] Настройка проекта, шрифты, CSS-переменные, reset, брейкпоинты
- [x] UI-кит: кнопки (2 цвета, 2 размера, иконки, `:focus-visible`), чекбокс
- [ ] UI-кит: поля ввода, селект, SVG-спрайт
- [ ] Главная страница, десктоп
- [ ] Адаптив и мобильное меню
- [ ] JS: таймер, попап с формой, маска телефона, галерея, аккордеон
- [ ] Страницы моделей
- [ ] Lighthouse, доступность, деплой

## Подходы

- Логические CSS-свойства (`padding-inline`, `inline-size`)
- Доступность: семантическая разметка, видимый фокус с клавиатуры, `aria-hidden` у декоративных иконок
- Коммиты в формате Conventional Commits

## Запуск

```bash
npm install
npm run dev
```

> Основной шрифт коммерческий и не входит в репозиторий — без него используется резервный (Arial).
